# TodoList — Objective-C

A UIKit task-management app written in Objective-C, built to demonstrate practical Objective-C and classic UIKit development.

## Highlights

- Create, edit and delete tasks
- Separate Todo, In Progress and Done flows
- High, medium and low priority sections
- Search by task name with `UISearchBar`
- Local persistence with `NSUserDefaults` and secure archiving
- Table-view based UIKit interface

## Tech Stack

Objective-C, UIKit, UITableView, UISearchBar, NSUserDefaults, NSSecureCoding

## Run locally

1. Clone the repository.
2. Open `TodoListApp/TodoListApp.xcodeproj` in Xcode.
3. Build and run on an iOS Simulator.
